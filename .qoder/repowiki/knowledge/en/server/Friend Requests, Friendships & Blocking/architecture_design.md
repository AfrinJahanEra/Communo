Follows a strict three-layer MVC pattern within the module: `routes/friend.routes.js` mounts an Express Router under `/friends`, applies the shared `requireAuth` middleware and per-route `validate` middleware (from `../middleware/validate.js`) using Zod schemas from `validations/friend.validation.js`; `controllers/friend.controller.js` contains thin async handlers that delegate to `services/friend.service.js` and return responses via `utils/response` helpers (`sendOk`, `sendCreated`); `services/friend.service.js` holds all domain rules — resolving target users, enforcing self-send / block / duplicate-request checks, emitting WebSocket events through `sockets/emitters.js`, and normalizing Mongoose documents into a minimal public shape; `repositories/friend.repository.js` is a pure data-access layer over Mongoose models `Relationship` and `Block`, exposing symmetric queries (e.g. `findBetween`, `findBlockBetween`) that handle both request directions. Dependency direction is strictly one-way: routes → controllers → services → repositories → models, with no cross-imports back up the stack.
